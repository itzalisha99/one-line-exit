A one-line resignation letter for the make.fun bounty
[The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

The entry:

> I resign: I balanced the books and found my will to live filed under 'miscellaneous expenses'.

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt`. It is 94 characters, one line, and deterministic.
